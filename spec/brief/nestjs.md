# Dialect `nestjs`: the backend platform in TypeScript

What this dialect adds to the platform's sheet: the project is generated as NestJS 12 (ES modules) + Sequelize +
class-validator + LangChain.js in `build/` (never edit it). `dragonfly build`, `dragonfly install` (npm),
`dragonfly run` (node --watch), `dragonfly test` (node:test), `dragonfly migrate`. Full rules: `nuclear help nestjs`.
